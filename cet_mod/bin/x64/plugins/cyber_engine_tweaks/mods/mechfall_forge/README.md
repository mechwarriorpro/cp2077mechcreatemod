# MECHFALL // FORGE 77 — CET test mod

**Install:** copy this whole `mechfall_forge` folder into

```
Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/mechfall_forge/
```

Requires **Cyber Engine Tweaks**. The BT-7274 base mod (Nexus 35041) is **optional**; no base-mod
files are bundled or required. Bind the hotkey **MECHFALL // FORGE 77** in CET's Hotkeys panel,
then open the overlay.

`init.lua` is generated by `python3 tools/generate.py` — edit `tools/init.lua.template` and the root
JSON files instead of editing it directly.

What it does: 7 ImGui tabs — HANGAR · INTERNAL SYSTEMS · MECH FORGE · REACTOR LAB · SETTINGS ·
COMPAT · **IN-GAME PILOT** — with live power / mass / heat / RCS / ECM bars, subsystem authoring,
shape sliders, reactor lab, config exponents and pcall-wrapped optional base-mod hooks.

**IN-GAME PILOT:** `F6` (or the tab's DEPLOY button) spawns the vanilla **Militech Minotaur**
(`Character.q003_militech_mech`) plus drone/android/turret signature parts by TweakDB record id,
moves them each frame with `WorldTransform` / `SetWorldTransform`, reads continuous controls with
`registerInput` + `onUpdate`, and locks V into a COCKPIT / CHASE / ORBIT transform with
`Game.GetTeleportationFacility():Teleport`. **F7 / EMERGENCY RESET despawns everything.** Every game
call is `pcall`-wrapped; missing APIs degrade to PHANTOM mode. Assign the 12 `MECHFALL IN-GAME`
keys under CET Bindings and load an open-world save first. No meshes, rigs, animations, VO or
base-mod files are shipped. See `docs/INGAME_PILOT.md` for the full checklist and honest limits.

The browser `test_build.html` remains the main playable prototype and owns the visual modeling table
+ combat harness + procedural 3D pilot test.

Redscript/TweakXL/ArchiveXL are **not installed**; see `docs/integration/*.example`.
