# MECHFALL // FORGE 77 — CET test mod

**Install:** copy this whole `mechfall_forge` folder into

```
Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/mechfall_forge/
```

Requires **Cyber Engine Tweaks**. The BT-7274 base mod (Nexus 35041) is **optional**; no base-mod
files are bundled or required. Bind the hotkey **MECHFALL // FORGE 77** in CET's Hotkeys panel,
then open the overlay.

`init.lua` is generated by `python3 tools/generate.py` — edit `tools/init.lua.template` and the root
JSON files instead of editing it directly.

What it does: ImGui tabs for HANGAR · INTERNAL SYSTEMS · MECH FORGE · REACTOR LAB · SETTINGS with
live power / mass / heat / RCS / ECM bars, subsystem authoring sliders, shape sliders, reactor lab,
config exponents and pcall-wrapped optional base-mod hooks. The browser `test_build.html` remains
the main playable prototype and owns the visual modeling table + combat harness.

Redscript/TweakXL/ArchiveXL are **not installed**; see `docs/integration/*.example`.
